## Resource Tick
A very simple AddOn that shows server ticks for better viewing of health and mana regeneration.

![Resource tick spark on the mana/rage/energy bar](screenshots/tick.png)

If you would like to have more features added, please feel free to open an Issue

- [ManaTickTrackerPlus](https://github.com/DustinChecketts/ManaTickTrackerPlus) by DustinChecketts — original spark-on-mana-bar idea (MIT licensed).
- [Eat & Run, Mana & Health Regen Tick](https://wago.io/DgEh8a3hj) — the WeakAura Kamisayo links, which inspired the health/mana regen tick approach.
